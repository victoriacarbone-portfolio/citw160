The CSS Box Model

The CSS box model is the way browsers calculate the size and spacing of elements on a page. Every element is treated like a rectangular box made up of content, padding, a border, and a margin.

The content is the actual text or image inside the element. Padding adds space between the content and the border, the border wraps around the padding and content, and the margin controls the space outside the element. Understanding how these layers work together makes it much easier to control layout and spacing in CSS.

Padding, Borders, and Margins

Padding, borders, and margins are all used to control spacing, but they affect elements in different ways. Padding increases the space inside the element, which also expands the background color. Borders sit around the padding and content and help define the edges of an element. Margins add space outside the element and control how close it sits to other elements on the page.

Floating Elements

Floating elements allows boxes to be positioned next to each other instead of stacking vertically. In this layout, two boxes are floated to demonstrate how float affects positioning and document flow.

When an element is floated, it is removed from the normal flow of the page. This can cause layout issues if the parent container does not account for the floated elements, which is why clearing floats is necessary in many layouts.

Clearing Floats with Clearfix

Because floated elements are taken out of the normal document flow, their parent container can collapse and appear as if it has no height. This is a common issue when using float-based layouts. A clearfix method is used to fix this problem by forcing the parent container to properly wrap around its floated children. This allows the layout to remain stable and predictable.
