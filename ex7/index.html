What is Flexbox?

Flexbox, or the Flexible Box Layout, is a CSS layout system designed to make it easier to arrange elements within a container. Unlike float-based layouts, Flexbox was created specifically for layout and alignment, which makes it more predictable and easier to control.

Flexbox is considered better than floats for most layouts because it allows elements to align, space, and resize dynamically without needing clearfixes or extra hacks. It also adapts more naturally to different screen sizes, making it a strong choice for responsive design.

Flex Containers & Flex Items

A Flexbox layout consists of a flex container and its flex items. The container is the parent element that has display: flex applied, and the flex items are the direct children inside it.

Flexbox works in one dimension at a time, either in a row or a column. The main axis is the primary direction the items are laid out, while the cross axis runs perpendicular to it. When flex-direction is set to row, the main axis runs horizontally. When it is set to column, the main axis runs vertically.

Flexbox Properties

Flexbox provides several properties that control spacing and alignment. The justify-content property aligns items along the main axis, while align-items controls alignment along the cross axis. These properties make it easy to center content or distribute space evenly.

The flex-wrap property allows items to move onto a new line when there is not enough space, preventing overflow. Individual flex items can be further controlled using flex-grow, flex-shrink, and flex-basis, which determine how items resize relative to one another within the container.

Nested Flexbox

Flexbox containers can also be nested inside one another to create more complex layouts. In this example, a flex container is placed inside another flex container, allowing different sections of the page to be aligned independently.

Nesting Flexboxes makes it possible to build full page layouts, such as headers, main content areas, and sidebars, without relying on floats or positioning hacks.
