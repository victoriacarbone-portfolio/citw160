Main Content

CSS Grid is a layout system that allows developers to create rows and columns on a webpage. It makes it easier to build structured layouts without using floats or complicated positioning techniques.

In this example, the header spans across both columns while the sidebar and main content sit next to each other. A second section appears below the main content to show how grid items can be arranged in multiple rows.

For a more advanced example, view the page that demonstrates a 12-column responsive grid layout.

Fun Fact About CSS Grid

CSS Grid works in two dimensions, meaning it can control both rows and columns at the same time. This makes it more powerful than many older layout techniques.

Many modern websites use a 12-column grid system because it provides flexible layout combinations such as 6/6, 4/4/4, or 8/4 column splits.
